# Free AI Resources

With API key subscriptions becoming the new norm, I wanted to know what was
still out there for $0. Yes, you can run a model locally for free (resources
permitting) — I plan to add guides for that once I figure it out myself. For
now, this repo catalogs free AI sites: some completely free, some freemium.
Where a site has a membership, I note whether the free tier is still worth
using, and I label each site accordingly.

This list is organized by **user experience**, not popularity. The best free
tier is the one you can actually use without fighting it.

## A note on your data

These are mostly free sites, and I cannot guarantee what happens to anything
you send them. If a site asks you to register or sign in with Google, I'd
strongly suggest a throwaway account and a password you don't use anywhere
else. Be smart about it.

## Inclusion rule

A site qualifies if its free tier offers **unlimited conversations** — no
message cap, no hard paywall mid-chat. Queue waits, ads, slower models, or
reduced memory are acceptable limitations. A free tier that cuts you off
after N messages does not qualify.

For a site to make this guide it has to have free unlimited use at the free
tier. Every link here provides something of value. I will not post garbage
links.

## How I test

- Signed out, or a fresh account
- Fresh browser profile, no extensions
- Core function tried 5–10 times
- Wait, cap, paywall, or forced signup noted
- Date recorded

When the official description and what I actually observed disagree, I report
both. The observed line is marked with ↳.

## Tier 1 — Sign up and go

No account, no friction. Open the page and use it.

- [Perchance AI Chat](https://perchance.org/ai-chat) — Browser-based character
  chat with custom personas and no login. Unlimited messages, per-generator
  rules. *No membership.* `NSFW: varies by generator`
- [NoTrack.ai](https://notrack.ai) — Stateless, uncensored chat. No account,
  no memory between sessions, 46 languages. *No membership.* `NSFW: unrestricted`

## Tier 2 — Free tier that doesn't feel like a trial

Account needed, but the free experience is genuinely usable.

- [Spicychat](https://spicychat.ai) — Uncensored roleplay, large bot library,
  fast responses. Free tier feels unrestricted in practice. *Free + paid.*
  `NSFW: filter available`
  ↳ ⚠️ Site lists queue priority as a paid perk, but I found no queue
  (tested 2026-09-29, signed out, fresh browser, 8 bots).

## Legend

**Membership**
- *No membership* — fully free, nothing to buy
- *Free + paid* — free tier is functional; paid tier exists for extras

**NSFW**
- `NSFW: none` — not permitted
- `NSFW: filter available` — toggle or filter, SFW by default
- `NSFW: varies by generator` — depends on the specific tool
- `NSFW: unrestricted` — no filter

**Observed notes**
- `↳` — official description and observed experience differ; both reported
- Dates are YYYY-MM-DD and reflect when I last tested
