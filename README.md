# Free_AI_Resources
                                              About

With API key subscriptions becoming the new norm. I wondered what was out there for $0 dollars. Yes I am fully aware you can run a model locally for free (granted you have the resources or find the right model for your device). This repository will eventually have guides to help get that off the ground (Once I figure it out myself).


At the moment this is to catalog completely free AI sites. Or if they have a membership the free version they offer is still decent. I will label each site if it has a membership or not. 

If you stumble onto this page and you know of any AI sites that could be added to this list please e-mail me at: NightmareZer0@protonmail.com

Please take it consideration that being free you might need to invest more time into it. Also I have no clue what happens to the data you enter on these sites. Just be smart about it.
