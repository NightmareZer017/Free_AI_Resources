# Contributing

Thanks for wanting to add to the list. Two things matter most here:
**the site must be genuinely free to use**, and **the entry must follow the
format** so the list stays scannable.

## Does the site qualify?

A site qualifies if its free tier offers **unlimited conversations** — no
message cap, no hard paywall mid-chat. These are fine:

- Queue waits
- Ads
- Slower or smaller models on free
- Reduced memory / context on free
- A paid tier that adds convenience

These are **not** fine:

- Free tier cuts you off after N messages
- Requires a credit card to start
- No free chat function at all
- "Free trial" that expires

If you're unsure, submit it and say so. I'd rather review a borderline site
than miss a good one.
